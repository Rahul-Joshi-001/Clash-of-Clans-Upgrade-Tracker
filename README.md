# ClashTrack — Clash of Clans Upgrade Tracker

ClashTrack is a web application that helps Clash of Clans players track their village progress and manage upgrades in one place.

## How to Run the Project

### Step 1: Download the Repository

Open the [GitHub Repository](https://github.com/Rahul-Joshi-001/Clash-of-Clans-Upgrade-Tracker), click **Code → Download ZIP**, and extract the downloaded ZIP file.

### Step 2: Run the Application

Open the extracted project folder and double-click **`ClashTrack-Run.bat`**.

Wait for the backend and frontend servers to start. The first run may take some time if dependencies need to be installed.

### Step 3: Open ClashTrack

Open your browser and visit:

**http://127.0.0.1:5173**

Register an account or log in to start tracking your village.

## About the Project

ClashTrack provides a centralized dashboard for managing and monitoring Clash of Clans village upgrades.

### Features

- **Dashboard:** View your village progress.
- **Building Tracker:** Track building levels and upgrades.
- **Hero Tracker:** Monitor hero progression.
- **Laboratory:** Track troop and spell upgrades.
- **Pet Tracker:** Manage pet levels.
- **Equipment Tracker:** Track hero equipment.
- **Wall Tracker:** Monitor wall upgrades.
- **Village Import:** Import supported village JSON data.

## Technology Stack

- React
- Vite
- Tailwind CSS
- Node.js
- Express.js
- Axios
- JWT Authentication
- Database configured in the backend

## Project Structure

- `Backend/` — Server, API routes, authentication, and data processing.
- `frontend/` — React application and user interface.
- `ClashTrack-Run.bat` — Launcher for starting the application.
- `README.md` — Project documentation.
